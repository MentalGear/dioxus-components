# Demo avatars

Eight abstract, geometric avatars for the component demos (avatar, item,
dashboard, chat kit). Each is a flat 80 x 80 SVG of two to four shapes (circles,
rects, arcs, a triangle) on a muted field, in a shared palette that reads on the
light and the dark page. There are no faces, gradients, text or photos, and the
names they stand for are invented.

They are bundled so the demos work offline and on GitHub Pages, and so no demo
hot-links a photo of a real person. The avatar's own CSS clips each square to a
circle or rounded square.

No third-party artwork or library is involved. The files are generated by
[`scripts/gen-demo-avatars.mjs`](../../../scripts/gen-demo-avatars.mjs), a
dependency-free Node script (standard library only), and the SVGs are written
by that script, so edit the script rather than the files.

## Regenerating

```sh
node scripts/gen-demo-avatars.mjs
```

The output is deterministic: a hash of the name picks one of eight
compositions, a palette and a small offset (a clash with an earlier name steps
to the next free one), so running it again rewrites byte-identical files. To
change the look, edit `PALETTES` or `TEMPLATES` in the script. To add a person,
add the name to `NAMES` and run it; the file is `<first>-<last>.svg`, which
`demo_avatar` in `preview/src/main.rs` (or an `asset!` path in a demo) then
refers to.
