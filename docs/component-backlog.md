## Recommendations

1. **Take first: `ComboboxMulti`** — small, additive, reuses house infrastructure, no competing implementation, invisible to anyone only watching the upstream PR queue.
2. **Split PR #283 into three separate decisions**; never merge it as a branch. SplitPane/Resizable is the strongest sub-feature; TableOfContents is complete but P2 by scope; Schedule should be rejected.
3. **Nested submenu is the highest-value gap with no clean source** — budget it as fresh design work against Radix `Sub`/`Portal` semantics, using `molikto`'s stale patch only to understand the problem's shape.
4. **Reject Carousel and Schedule outright**; treat Command as build-from-existing-parts, not a port.
5. **DragAndDropBoard needs its panic closed before it is a candidate at all** — a verified open bug in the only source for the feature.
6. All of the above under the standing hygiene rules: oracle first, provenance headers, untrusted-content discipline, no fork `Cargo.toml` edits.
