## Fresh-session order (2026-09-04)

The table below is ranked by take-order already; this block is a **recommendation for what a fresh session should pick up first**, layered on top of it — easy to reverse, not a renumbering of the rows. Rationale: fix what's broken before building more, cheap infrastructure before expensive components, and keep CI-gated items visibly separate from everything else since they aren't sequenced at all (they wait on the user lifting the CI freeze).

**Environment note (2026-09-04):** this sandbox got a working Playwright container for the first time this session — `dx` 0.7.9 and the wasm32 target installed, chromium/firefox/webkit browsers all installed, `dx build --web --release` succeeds. A fresh session hitting the same proxy should expect the identical failure and know the workaround rather than rediscovering it. A firefox+webkit calibration run (row 4) was started in this same sandbox and was still in progress when this session ended — its result is unknown here; a fresh session should check it before doing further calibration-related work.
