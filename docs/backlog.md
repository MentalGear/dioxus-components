## Fresh-session order (2026-09-03)

The table below is ranked by take-order already; this block is a **recommendation for what a fresh session should pick up first**, layered on top of it — easy to reverse, not a renumbering of the rows. Rationale: fix what's broken before building more, cheap infrastructure before expensive components, and keep CI-gated items visibly separate from everything else since they aren't sequenced at all (they wait on the user lifting the CI freeze).

1. **Known bugs first** — row 26 (client-side navigation leaves the previous route's DOM mounted: a leaked overlay can collide with a live one in the accessibility tree), rows 36–38 (the three axe findings filed by the 2026-09-03 axe-coverage round: row 36 `SelectTrigger` id desync against `SelectList`'s `aria-labelledby`, row 37 the dashboard email client's `nested-interactive` violation, row 38 the `/component/block/` route family's missing page-level heading/landmark), and row 25 if still open (`ContextMenu`/`Menubar` submenu `aria-labelledby` — marked landed 2026-09-03, re-check it hasn't regressed before treating it as done).
2. **Row 31a** — design tokens (+ the generated utility sheet + the shared interaction-rules layer), since every later styling decision depends on the token set existing first.
3. **Row 32 execution + row 31b** — the styling-engine decision is made (plain `dx-`-prefixed CSS, no `css_module` hashing); execute the mechanical migration off `#[css_module]` across the 47 themed components, plus 31b's literal-value migration onto row 31a's tokens.
4. **Phase 5 residual + nested submenus** — row 10's remaining scope (shift/size clamping, `ContextMenu`'s point-anchor clamp) together with nested submenus from [`component-backlog.md`](./component-backlog.md) (both were blocked on the top-layer engine, which has since landed, and both are the kind of foundational overlay work later components build on).
5. **Row 27** — the nine styled-only components (Alert, Breadcrumb, Button Group, Empty, Field, Input Group, Kbd, Spinner, Native Select), authored once against the row-31a tokens in the winning styling system.
6. **The cheap primitives wave** — Command, then Input OTP, then Drawer/Navigation Menu/Resizable, per the re-rated effort table in [`component-backlog.md`](./component-backlog.md).
7. **CI reactivation items** — rows 4, 22, 33, whenever the user lifts the CI freeze. These are **user-gated, not sequenced**: they don't wait their turn behind 1–6, they wait on a decision outside this ranking entirely, and can land whenever that decision changes regardless of where the rest of this list stands.

Row numbers above are not renumbered — this is a reading order layered on the table, not a new ranking of it.
